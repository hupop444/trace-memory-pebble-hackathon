# TRACE Pebble 到货验收清单

## 现在已经准备好的部分

- 三设备网页：`http://127.0.0.1:8789/`
- 三设备独立 WebSocket、状态、压力、光敏、事件计数和振动命令
- 两台虚拟 Pebble，可在真板到货前完整测试操作
- 同一份固件自动生成唯一设备 ID 和唯一热点名
- 六轴默认关闭，不占针脚，不参与数据

## 每块 ESP32-C3 SuperMini 的接线

先拔掉 Type-C，再接线。

| 分组 | SuperMini | 模块端 |
| --- | --- | --- |
| 供电 | `3V3` -> 一母转三母分线 | 压力 `V`、光敏 `V`、振动模块 `V` |
| 共地 | `GND` -> 一母转三母分线 | 压力 `G`、光敏 `G`、振动模块 `G` |
| 压力信号 | `GPIO0` | 压力 `S` / `AO` |
| 光敏信号 | `GPIO1` | 光敏 `S` / `AO` |
| 振动控制 | `GPIO5` | 振动模块 `S` / `IN` |

不要把模块的 `V` 接到 GPIO，也不要把裸马达直接接到 GPIO。这里的接法只适用于当前已经验证过、带驱动电路的振动模块。

## 当前 ESP32-S3 的接线保持不变

| 模块 | 信号针脚 |
| --- | --- |
| 压力 | `GPIO1` |
| 光敏 | `GPIO2` |
| 振动模块 | `GPIO8` |

三块模块仍然共用 `3V3` 和 `GND`，使用一母转三母分线即可。

## 两块新板到货后的固定顺序

1. 看金属屏蔽罩或商品标签，确认是 `ESP32-C3 SuperMini`。
2. 每次只把一块新板接入电脑，其余新板先不接。
3. 按上表插好三块模块，检查 `3V3` 与 `GND` 没有接反。
4. 在仓库 `hardware` 目录运行 `.\tools\flash-trace-pebble.ps1 -Board C3 -Port COMx`，把 `COMx` 换成当前新板的端口。
5. 手机连接该板的唯一热点 `TRACE-Pebble-XXXXXX`，访问 `192.168.4.1`。
6. 在页面里保存 `TRACE-Bridge` 的 Wi-Fi 名称和密码。
7. 手机切回正常网络，电脑保持连接原有互联网 Wi-Fi，并开启 `TRACE-Bridge` 热点。
8. 打开 `http://127.0.0.1:8789/`，确认对应位置由“虚拟设备”变成真实 Pebble。
9. 分别遮挡光敏、按压薄膜、点击振动回放，确认只更新当前这一块。
10. 给第二块新板重复步骤 2-9。

## 每块板的通过标准

- 页面显示唯一 `trace-xxxxxx`，三块 ID 不重复。
- 静置时压力原始值接近其基线。
- 按压后只有当前设备事件数增加。
- 遮挡光敏后只有当前设备环境光数值明显变化。
- 点击当前设备“振动回放”时，只有当前模块振动。
- 电脑仍连接原有互联网 Wi-Fi，不连接 `TRACE-Pebble-XXXXXX`。
