# 接线与装配定义

## 四个主体之间的连接

| 主体 | 接口 | 接到 ESP32-S3 | 作用 |
|---|---|---|---|
| 光敏电阻 LDR | J2-1 = 3V3；J2-2 = LDR_SENSE | J1-4 / GPIO4 / ADC1_CH3 | 环境光；越亮，ADC 值通常越高 |
| FSR 402 薄膜压力传感器 | J3-1 = 3V3；J3-2 = FSR_SENSE | J1-5 / GPIO5 / ADC1_CH4 | 按压强度；按得越重，ADC 值通常越高 |
| 压电振动片 | J4-1 = PIEZO+；J4-2 = PIEZO- / GND | J1-6 / GPIO6 / ADC1_CH5 | 敲击/振动事件包络 |
| ESP32-S3-DevKitC-1 | USB-C 供电；3V3 与 GND 向传感前端供电 | - | 采样、标定与无线传输 |

## 线束定义

- J2 / LIGHT：Pin 1 红线 `3V3`，Pin 2 白线 `LDR_SENSE`。
- J3 / PRESSURE：Pin 1 红线 `3V3`，Pin 2 黄色 `FSR_SENSE`。
- J4 / VIBRATION：Pin 1 橙线 `PIEZO+`，Pin 2 黑线 `GND`。
- 三个连接器均采用 JST-PH 2.0 mm。板端建议 `B2B-PH-K-S(LF)(SN)`，线端 `PHR-2 + SPH-002T-P0.5S`。
- Pin 1 在 PCB 上使用方焊盘、三角丝印或“1”字样；线束两端热缩管必须有通道色标。

## 上电前检查

1. 断电测量 J2-1、J3-1 到 3V3 导通，J4-2 到 GND 导通。
2. 确认 J2-2、J3-2、J4-1 均不与 3V3 或 GND 硬短路。
3. 压电片必须经 J4 进入调理电路；禁止直接飞线到 GPIO6。
4. USB 供电后，静止状态下 GPIO4/5/6 电压必须处于 0-3.3 V 范围。
5. 首次敲击压电片时用示波器观察 `VIB_ENV` 与 `VIB_ADC`；D2 钳位节点不应长期超过约 3.55 V。

## 标定顺序

1. LDR：记录暗环境、常用环境、强光三点。
2. FSR：以“未触碰、舒适触碰、明确按压”三档建立个体阈值，不以硬壳凸点迫使用户用力。
3. 压电：记录佩戴/移动噪声与目标敲击峰值，再设置阈值和 60-120 ms 去抖/锁止时间。

## 关键禁止事项

- 不给传感器使用 5 V 激励；本设计的模拟域统一为 3.3 V。
- 不把光敏或 FSR 模块的 5 V 模拟输出接入 ESP32-S3。
- 不把压电片直接接 GPIO；压电片即使电流很小，也可能产生高幅值瞬态。
- 不把 FSR 当作精密称重传感器；它更适合人机触摸、相对力度和事件判断。
