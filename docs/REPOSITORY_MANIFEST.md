# Repository manifest

This repository intentionally contains reproducible source and selected presentation outputs.

Included:

- Web application source and lockfile.
- ESP32 firmware, serial bridge and gateway tools.
- Protocol contracts and acceptance pages.
- Parametric CAD and verified STL outputs.
- KiCad source, BOM, schematic exports and QA documents.
- Selected visual references and presentation renders.

Excluded from Git history:

- `node_modules`, `.next`, `dist` and compiler output.
- Downloaded Arduino / OpenSCAD toolchains.
- npm and Arduino caches.
- Private `.env` and `trace_secrets.h` files.
- Duplicate ZIP delivery bundles.

Large delivery bundles should be attached to a tagged GitHub Release so the source history remains reviewable.
